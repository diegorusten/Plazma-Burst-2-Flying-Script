# PB2 Flying Script (AutoHotkey v2)

An AutoHotkey v2 script that automates flying movement and FPS/physics switching inside PB2.

The script allows fast flying by controlling mouse movement while switching between different FPS, physics, and logic settings.

## Requirements

- Windows
- AutoHotkey v2.0+
- Fullscreen game mode recommended

---

# Hotkeys

| Key | Action |
|---|---|
| **F1** | Start script |
| **F2** | Stop script |
| **Shift + F** | Toggle High 60 FPS / Low 30 FPS |
| **Right Click (High 60 FPS)** | Start flying |
| **Right Click (Not High 60 FPS)** | Show current FPS and physics |
| **Alt + Right Click** | Toggle right click passthrough (shooting/slicing) |
| **Shift + Mouse Wheel** | Increase/decrease flying movement range |
| **Shift + R** | Toggle Low 20 FPS / Low 30 FPS |
| **Shift + E** | Change to High 30 FPS |
| **Shift + Q** | Change to Low 60 FPS |

---

# How to Fly Fast

1. Open the script.
2. Start the game in fullscreen mode.
3. Press: F1
4. Press: Shift+F
5. Hold: R_Click and F
